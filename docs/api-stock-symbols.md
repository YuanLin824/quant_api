# 标的代码（StockSymbols）

[← 返回目录](../API.md)

> 所有接口需要 JWT 认证，请在请求头中携带 `Authorization: Bearer <access_token>`

## 说明

### 数据来源

通过 [`stock-sdk`](https://www.npmjs.com/package/stock-sdk)（npm 包，HTTP 公开数据源）
获取代码列表，**每日 08:00（Asia/Shanghai）同步入库**，并提供查询接口。

> 底层的 `StockSdkService` 只提供**实时获取**能力（不落库），本模块把结果**持久化**，
> 因而可离线查询、可被其他模块直接查表复用。

### 覆盖市场与代码格式

| market | 市场 | 代码格式                             |
| ------ | ---- | ------------------------------------ |
| `cn`   | A股  | `sh600000` / `sz000001` / `bj430047` |
| `hk`   | 港股 | `hk00700`                            |
| `us`   | 美股 | `usAAPL`                             |
| `fund` | 基金 | `005827`（**无前缀**）               |

A 股的交易所前缀**编码在代码里**（上游把 A 股视作一个整体），故没有 `sh`/`sz` 这类单独的市场值。

> 基金代码是纯数字，可能与 A 股的**纯数字形式**同形（如 `000001` 既是某只基金、也是平安银行的数字代码），
> 但 A 股入库的是带前缀的 `sz000001`，故主键不会冲突——查询时按 `market` 区分即可。

> **入库前会做格式规范化**——上游三个市场的原始格式并不统一：
>
> | 市场 | 上游原始格式                                               | 入库格式  |
> | ---- | ---------------------------------------------------------- | --------- |
> | A股  | `sh600036`（已带前缀）                                     | 原样保留  |
> | 港股 | `00700`（纯数字）                                          | `hk00700` |
> | 美股 | `105.AAPL`（东财 secid，105=NASDAQ / 106=NYSE / 107=AMEX） | `usAAPL`  |

### 表里只有代码

`stock-sdk` 的 `codes.*` 返回**纯字符串数组**，不提供名称、每手股数、小数位等属性，
因此 `stock_symbols` 表只有 `market` 与 `code` 两列。

> 需要**名称**等信息时，可用内部的 `WestockDataService.search`（带名称，但需关键词）
> 或 `TdxService.getStockList`（带名称与每手股数，但只覆盖沪深京）—— 两者都是内部服务，
> 当前**不对外暴露 HTTP 接口**。

### 同步语义

- **upsert**：以 `code` 为唯一键，不存在则新增、`market` 有变化时更新、无变化则不写入
- **只增不删**：已退市的历史记录保留
- 各市场相互独立：单个失败只记录并继续，下次任务会补上

> 本表**没有软删除**（`code` 直接作主键）：要删标的直接硬删
> （`DELETE FROM stock_symbols WHERE code = '...'`）。

## 手动触发同步

用于首次初始化或失败补跑。

**请求**

```
POST /api/stock-symbols/sync
Authorization: Bearer <access_token>
```

**响应**

```json
{
  "code": 200,
  "message": "同步完成",
  "data": {
    "results": [
      { "market": "cn", "fetched": 5564, "stored": 5564, "inserted": 5564 },
      { "market": "hk", "fetched": 4695, "stored": 4695, "inserted": 4695 },
      { "market": "us", "fetched": 13538, "stored": 13538, "inserted": 13538 },
      { "market": "fund", "fetched": 27869, "stored": 27869, "inserted": 27869 }
    ],
    "durationMs": 8600
  }
}
```

**字段说明**

| 字段       | 说明                               |
| ---------- | ---------------------------------- |
| `market`   | 市场：`cn`/`hk`/`us`/`fund`        |
| `fetched`  | 上游返回条数（去重前）             |
| `stored`   | 去重后实际入库条数                 |
| `inserted` | 本次**新增**条数（已存在的不计入） |
| `error`    | 该市场失败原因，成功时不出现       |

> 各市场相互独立，单个失败只记录在该市场结果里，其余照常同步，故该接口**始终返回 `200`**
> （除非触发并发保护）。

**错误响应**

- `401` - `访问令牌无效或已过期`（由守卫抛出）
- `409` - `同步任务正在执行中，请稍后再试`（上一次同步未结束，含 cron 与手动触发撞车）
- `429` - 触发全局限流（每 60 秒 60 次）

## 查询数量统计

**请求**

```
GET /api/stock-symbols
Authorization: Bearer <access_token>
```

**响应**

```json
{
  "code": 200,
  "message": "获取成功",
  "data": { "cn": 5564, "hk": 4695, "us": 13538, "fund": 27869 }
}
```

**字段说明**

| 字段                        | 说明                                         |
| --------------------------- | -------------------------------------------- |
| `cn` / `hk` / `us` / `fund` | 各市场的代码数量；某市场同步失败时键可能缺失 |

> **本接口只返回数量，不返回具体代码列表。**
> 具体代码的获取能力（`StockSymbolsService.getByMarket`）保留在 service 层，
> 供其他模块按需注入使用；也可直接查 `stock_symbols` 表。

**错误响应**

- `401` - `访问令牌无效或已过期`（由守卫抛出）
- `429` - 触发全局限流（每 60 秒 60 次）
