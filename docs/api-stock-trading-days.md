# 交易日历

[← 返回目录](../API.md)

> 本接口需 `Authorization: Bearer <access_token>`。
>
> 限流在全局默认（每 60 秒 60 次）之上：手动同步是重操作（真实调用上游 API），收紧到每小时 5 次。

## 手动触发同步

立即从同花顺拉取近一年的 A 股交易日并增量落库，等价于定时任务（每天凌晨 3 点）的即时执行。

**请求**

```
POST /api/stock-trading-days/sync
```

**限流**: 每小时最多 5 次

**请求示例**

```
POST /api/stock-trading-days/sync
Authorization: Bearer <access_token>
```

**响应**

```json
{
  "code": 200,
  "message": "同步完成",
  "data": {
    "fetched": 242,
    "skipped": false,
    "costMs": 857
  }
}
```

| 字段      | 类型    | 说明                           |
| --------- | ------- | ------------------------------ |
| `fetched` | integer | 上游返回的交易日数             |
| `skipped` | boolean | 是否因已有同步在进行而整体跳过 |
| `costMs`  | integer | 耗时（毫秒）                   |

> ⚠️ 本接口会**真实调用上游同花顺**。同步按 `date` 做 upsert：已有日期更新、新日期插入，
> **不会删除任何历史数据**——上游返回的是「近一年」窗口，更早的交易日会一直保留在表中。
>
> 若已有同步正在进行（定时任务触发，或上一次手动触发尚未结束），返回的 `skipped` 为 `true`、
> `message` 为「已有同步正在进行中」，此时**不会重复拉取上游**。

**错误响应**

- `401` - 未携带令牌或令牌无效
- `429` - 触发接口限流（每小时 5 次）
- `502` / `503` / `504` - 上游同花顺异常，具体见 [API.md 错误码说明](../API.md#错误码说明)
